# advent-of-code-2025
Solutions for the Advent of Code 2025

## Requirements

- Node.js 18 or later
- This project uses **ES Modules** (`"type": "module"` in `package.json`).

## Run the solutions

From the repository root, execute the desired solution:

### Day 1

```bash
node Day_1/src/AoC_day_1_Part_1.js
node Day_1/src/AoC_day_1_Part_2.js
```

### Day 4

```bash
node Day_4/src/day-4.js
```

### Day 7

```bash
node Day_7/src/day-7.js
```

### Day 10

```bash
node Day_10/src/day_10.js
```
